# رَصِيـن | RASEEN 💎
### سوق الأصول والأدوات الرقمية الاحترافية وقوالب Canva
**رصيدك الذكي من الأدوات والخبرات الجاهزة**

---

## 🌟 نظرة عامة (Overview)
منصة **رَصين (RASEEN)** هي السوق العربي المتخصص في بيع وتوزيع الأصول الرقمية، شيتات إكسل المحاسبية والإنشائية، قوالب نوشن، نماذج العقود القانونية، وحزم تصاميم السوشيال ميديا وعروض الاستثمار.

تتميز المنصة بدمج **استوديو كانفا التفاعلي (Canva Studio)** المباشر في المتصفح، والذي يتيح للمستخدمين تخصيص وتعديل قوالبهم فوراً وتصديرها بصيغة A4 PDF للطباعة أو فتحها وتعديلها مباشرة في حساباتهم على منصة Canva.

---

## 🚀 المميزات الرئيسية (Key Features)

1. **السوق الرقمي الشامل (Digital Marketplace):**
   - 36 منتجاً معتمداً مقسمة على 5 فئات رئيسية (شركات، محاسبة، هندسة، طلاب، أفراد وإنتاجية).
   - باقات التوفير الحصرية (Curated Bundles) بخصومات تصل إلى 40%.
   - دعم التصفية متعددة المستويات حسب التخصص ونوع الملف (Excel, Notion, PowerPoint, Word/PDF, Canva, CAD/Revit, AI Prompts).

2. **استوديو تخصيص القوالب الذكي (Canva Studio - `/editor`):**
   - 5 قوالب أعمال أساسية (سيرة ذاتية ATS، فاتورة ضريبية، منشور إنستجرام/لينكدإن، عقد شراكة ملزم، شهادة اعتماد).
   - لوحة تحكم فورية في النصوص والبيانات.
   - 5 لوحات ألوان ملكية معتمدة (ذهب رَصين، الأزرق التنفيذي، الزمرد، البنفسجي، والعنابي).
   - تصدير فوري بدقة A4 للطباعة وحفظ PDF.
   - تكامل ومزامنة مباشرة مع منصة Canva.

3. **أدوات الاستقطاب المجانية (Free Lead Magnets - `/tools`):**
   - حاسبة المعدل التراكمي الجامعي (GPA Calculator).
   - مولد الفواتير الإلكترونية المباشر (Invoice Generator).
   - حاسبة ضريبة القيمة المضافة لدول مصر والخليج (VAT Calculator).
   - محول الوحدات الهندسية الشامل (Unit Converter).

4. **بنية تحتية وقاعدة بيانات دائمة (Database & APIs):**
   - Prisma ORM مع قاعدة بيانات مهيأة للمنتجات، الفئات، الطلبات، وبوابات الدفع.
   - نظام توليد رموز تحميل مشفرة بمفاتيح HMAC-SHA256 صالحة لـ 48 ساعة وبحد أقصى 10 تنزيلات.
   - دعم عملات متعددة (EGP, SAR, AED, USD) مع تحويل فوري للأسعار.

## 🛠️ البنية التقنية (Tech Stack)

* **الإطار البرمجي:** [Next.js 15 (App Router)](https://nextjs.org/)
* **واجهة المستخدم:** React 19, Tailwind CSS, Lucide Icons, Cairo Font (RTL Arabic First)
* **إدارة الحالة:** [Zustand](https://github.com/pmndrs/zustand)
* **قاعدة البيانات:** [Prisma ORM](https://www.prisma.io/)
* **النشر والاستضافة:** [Vercel](https://vercel.com/)

## 📦 التثبيت والتشغيل محلياً (Local Setup)

```bash
# 1. استنساخ المستودع
git clone https://github.com/mohamed-helmy/raseen.git
cd raseen

# 2. تثبيت الحزم
npm install

# 3. إعداد وتغذية قاعدة البيانات
npx prisma generate
npx prisma db push
node prisma/seed.js

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## 🚢 النشر على Vercel (Deployment to Vercel)

1. اربط حساب GitHub الخاص بك بمنصة [Vercel](https://vercel.com).
2. اختر المستودع `mohamed-helmy/raseen`.
3. سيتعرف Vercel تلقائياً على إعدادات Next.js 15.
4. اضغط **Deploy**!
